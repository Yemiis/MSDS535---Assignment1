# MSDS535---Assignment1
Coursework for MSDS 535 demonstrating recursion, user input handling, switch-case statements, and exception handling through Fibonacci and Calculator Java applications.

## Part 1: Fibonacci Series
- Implemented using recursion
- Accepts runtime user input
- Handles invalid input using exception handling

## Part 2: Simple Calculator
- Supports 7 operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Maximum
  - Minimum
  - Random number generation
- Uses switch-case and methods
- Includes runtime exception handling

## How to Run
Compile:
javac Fibonacci.java Calculator.java

Run:
java Fibonacci
java Calculator
